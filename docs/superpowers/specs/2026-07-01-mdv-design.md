# MDV (Markdown Viewer) 仕様書

> 作成日: 2026-07-01
> 目的: Win11ネイティブの Markdown 表示専用デスクトップアプリ「MDV」の設計仕様を確定する。
> ステータス: ユーザー承認済み（設計案）→ 本仕様書のレビューへ

---

## 1. 概要

- **MDV** = Windows 11 ネイティブの **Markdown 表示専用** デスクトップアプリ
- **閲覧専用**（編集モードなし）
- **日本語 UI**
- GitHub 風のリッチな Markdown レンダリングを提供する

### 非目標（やらないこと）

- Markdown の編集・保存機能
- 複数タブ / マルチドキュメント表示（初版は単一ドキュメント）
- ファイルツリー / エクスプローラー機能
- クラウド同期・印刷の高度なレイアウト制御（初版スコープ外）

---

## 2. 機能要件

### 2.1 Markdown 対応範囲（GitHub 風フル対応）

| 機能 | 対応 |
|---|---|
| 見出し / 段落 / 強調 / リスト | ○ |
| 表 (テーブル) | ○ |
| コードブロック（シンタックスハイライト） | ○（highlight.js） |
| タスクリスト（チェックボックス） | ○ |
| 画像 | ○（ローカル相対パス含む） |
| リンク | ○ |
| LaTeX 数式 | ○（KaTeX） |
| Mermaid 図 | ○（Mermaid.js） |

### 2.2 ファイルの開き方（3 方式すべて）

1. **メニューから開く**（[ファイル] → [開く]）
2. **ドラッグ & ドロップ**（ウィンドウへ .md ファイルをドロップ）
3. **ファイル関連付け / 右クリック**（コマンドライン引数でパスを受け取る）

### 2.3 メニューバー（Win11 ネイティブ）

- **[ファイル]**
  - 開く
  - 終了
- **[表示]**
  - テーマ切替（ライト / ダーク / システムに合わせる）
  - 文字サイズ：拡大 / 縮小 / リセット
  - 再読み込み
  - ステータスバー表示切替

### 2.4 テーマ切替

- 右上アイコン（🌙 / ☀️）でライト / ダークを切替
- 「システムに合わせる」を含む 3 状態
- WebView2 内の CSS（github-markdown-css）も連動して切替

### 2.5 ステータスバー

- **左下** = エンコード（例: `UTF-8` / `UTF-8 (BOM)` / `Shift_JIS` / `UTF-16 LE`）
- **右下** = 改行コード（`CRLF` / `LF` / `CR` / `混在`）
- [表示] メニューから表示 / 非表示を切替可能

### 2.6 設定の永続化

次回起動時に以下を復元する:

- テーマ状態（ライト / ダーク / システム）
- 文字サイズ倍率
- ステータスバーの表示 / 非表示

## 3. 技術スタック

| 項目 | 採用 | 理由 |
|---|---|---|
| 言語 / ランタイム | **C# / .NET 9** | インストール済み（9.0.315） |
| UI フレームワーク | **WinUI 3（Windows App SDK）** | Win11 ネイティブの外観・メニュー |
| 描画方式 | **WebView2 + Markdig** | 数式・Mermaid・表を全て満たせる唯一の方式 |
| MD → HTML 変換 | **Markdig** | 拡張機能でGFM・数式等に対応 |
| スタイル | **github-markdown-css** | GitHub 風の見た目 |
| コード色付け | **highlight.js** | コードブロックのシンタックスハイライト |
| 数式 | **KaTeX** | LaTeX 数式レンダリング |
| 図 | **Mermaid.js** | Mermaid 図レンダリング |
| 配布 | **単一プロジェクト MSIX** | マニフェストでファイル関連付けを宣言、クリーンな配布 |

### 描画方式の選定理由

CommunityToolkit の `MarkdownTextBlock`（ネイティブ描画）も検討したが、**数式・Mermaid・複雑な表を満たせない**ため不採用。WebView2 にHTMLを流し込む方式なら、Web 技術の資産（KaTeX / Mermaid / highlight.js）をそのまま使える。

### 同梱リソースの方針

- KaTeX / Mermaid / highlight.js / github-markdown-css は**ローカル同梱**（オフライン動作・CDN 依存なし）
- HTML テンプレートにこれらを `<link>` / `<script>` で読み込む

## 4. アーキテクチャ

### 4.1 コンポーネント構成

| コンポーネント | 役割 |
|---|---|
| **MainWindow** | レイアウト組み立て（メニュー / WebView2 / ステータスバー） |
| **MarkdownRenderer** | Markdig 変換 + HTML テンプレート組み立て |
| **FileService** | ファイル読込 / エンコード判定 / 改行コード判定 |
| **ThemeService** | ライト / ダーク / システム連動の管理と適用（WebView2 の CSS も切替） |
| **SettingsService** | テーマ・文字倍率・ステータスバー表示状態を保存・復元 |
| **App 起動処理** | ファイル関連付け起動・コマンドライン引数・D&D の受け取り |

### 4.2 画面レイアウト

```
┌─────────────────────────────────────────────┐
│ [ファイル] [表示]              タイトル   🌙/☀️ │ ← メニューバー + テーマ切替アイコン
├─────────────────────────────────────────────┤
│         WebView2（Markdownレンダリング）      │
├─────────────────────────────────────────────┤
│ UTF-8                                  CRLF │ ← ステータスバー(左:エンコード / 右:改行)
└─────────────────────────────────────────────┘
```

### 4.3 データフロー（ファイルを開く）

1. ファイル指定（メニュー / D&D / 関連付け）
2. バイト読込 → **エンコード判定**
   - BOM 優先 → UTF-8 試行 → 失敗なら Shift_JIS
   - `System.Text.Encoding.CodePagesEncodingProvider` の登録が必要
3. **改行コード判定**（CRLF / LF / CR、混在は「混在」表示）
4. Markdig 変換 → HTML テンプレートに流し込み → WebView2 へ
5. ステータスバー更新（左:エンコード, 右:改行コード）

---

## 5. エラー処理・補足

- ファイルが開けない / 非テキスト → **日本語エラーメッセージ**を表示
- 文字サイズ変更は WebView2 の **ZoomFactor** で実現
- エンコード表示例: `UTF-8` / `UTF-8 (BOM)` / `Shift_JIS` / `UTF-16 LE`
- 画像のローカル相対パスは Markdown ファイルのある場所を基準に解決する

## 6. 環境メモ（確認済み）

- `.NET 9` インストール済み（`dotnet --version` → 9.0.315）
- **WinUI3 テンプレートは未インストール**（`dotnet new list` に出ない）
  - 実装前に導入が必要: `dotnet new install Microsoft.WindowsAppSDK.ProjectTemplates`
  - または Visual Studio の「.NET デスクトップ開発」+「Windows App SDK」ワークロード
- MSIX パッケージ化のため、**単一プロジェクト MSIX** 構成を想定
